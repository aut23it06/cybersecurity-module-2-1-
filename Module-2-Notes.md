# Cybersecurity Module 2 – Learning Notes

## 1. Introduction
Cybersecurity protects computers, networks, applications, and data from unauthorized access and attacks.

## 2. Linux Basics
Linux is an operating system widely used in cybersecurity.

Basic commands:
- `pwd` – Shows the current directory.
- `ls` – Lists files and folders.
- `cd` – Changes the directory.
- `mkdir` – Creates a new directory.
- `whoami` – Displays the current user.

## 3. Reconnaissance
Reconnaissance is the information-gathering stage of security testing.

- Passive reconnaissance: Collecting publicly available information without directly interacting with the target system.
- Active reconnaissance: Interacting with a target system to gather information. Perform it only with proper authorization.

## 4. Security Tools
- Nmap: Discovers hosts and scans ports on authorized systems.
- Wireshark: Analyzes network traffic.
- Burp Suite: Helps test web application security.
- OWASP ZAP: Helps identify web application security issues.

## 5. Safety Rules
- Test only systems you own or have permission to assess.
- Never access private data without authorization.
- Record findings and follow responsible disclosure practices.

## 6. Learning Outcome
I learned basic Linux commands, reconnaissance concepts, common security tools, and the importance of authorized security testing.
